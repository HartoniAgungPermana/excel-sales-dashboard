# 📊 **FlipMart Retail Sales Performance Dashboard – Portfolio Project**

![alt text](<resources/Dashboard Demo.gif>)

The **FlipMart Sales Performance Dashboard** is **an interactive business intelligence project** developed using **Microsoft Excel**. It showcases the ability to transform raw transactional data (2019–2022) into actionable business insights through a clean and dynamic dashboard design.

This project was built to demonstrate **data analysis, visualization, and storytelling skills** using Excel’s core analytical tools — **Pivot Tables, Pivot Charts, and Slicers** — while simulating a **real-world BI workflow** through external data connections.

The dashboard tracks key business metrics such as **Profit, Sales, Quantity Sold, and Transactions**, helping stakeholders monitor company performance across **markets, segments, and time periods**.

Designed with an emphasis on **clarity, usability, and analytical depth**, this project serves as a portfolio piece that bridges the gap between **technical competency and strategic decision-making**. 

# 💼 **Executive Summary**

![alt text](<resources/Dashboard Overview.png>)

Between **2019 and 2022**, FlipMart maintained steady business growth, achieving a total profit of **$1.46M** and total sales exceeding **$12.6M**. The company’s performance was largely driven by the **Technology** category, which contributed approximately **45% of total profit**, followed by **Office Supplies (35%)** and **Furniture (19%)**.

Regional analysis shows that the **United States and China** consistently ranked as the top profit-generating countries, together accounting for a substantial share of total revenue. However, the heavy concentration of profit in these markets indicates potential overreliance on specific regions.

Customer segmentation reveals that a **small number of high-value customers** drive a significant portion of total sales, underscoring FlipMart’s dependency on key accounts. While this presents opportunities for personalized relationship management, it also exposes risk if those customers reduce their purchases or switch suppliers.

Across the observed period, FlipMart demonstrated an overall **upward profit trend**, despite seasonal fluctuations. The continuous growth, especially in technology-related sales, reflects successful product positioning and evolving consumer demand toward tech products.

In summary, this project illustrates how **Excel-based analytics** can deliver valuable business insights — connecting data, visualization, and decision-making in one efficient framework.

# ⚙️ **How to Use**

1. 📥 **Download the files**  
   - This project uses an **external connection** between the dashboard and the dataset.  
   - Please download **both files** from this repository:  
     - [FlipMart_Dashboard.xlsx](FlipMart_Dashboard.xlsx)
     - [FlipMart_Dataset.xlsx](FlipMart_Dataset.xlsx)

2. 📁 **Keep both files in the same folder**  
   - Place both files in the **same directory** to ensure the external connection works properly.  
   - If Excel prompts you to update the data source path, simply point it to the dataset file in that folder.  

3. 🔓 **Enable content**  
   - Upon opening the dashboard, Excel may display a warning about external connections or macros.  
   - Click **“Enable Content”** to activate the full functionality.  

4. 🖱️ **Explore the dashboard**  
   - Use the **slicers** (Market, Segment, Order Date) to filter the data.  
   - KPIs and charts will update dynamically based on your selections.  

5. 🔧 **Turn off protection for deeper exploration**  
   - To simulate a **real-world BI workflow**, the workbook and all worksheets in `FlipMart_Dashboard.xlsx` are protected, and analysis sheets are hidden.  
   - You can disable protection and **unhide** the analysis sheets if you want to explore the underlying structure in detail.
